# Security and distribution notes

Source preview only. Not a penetration test, SCA report, or completed security audit.

- Windows global shortcuts use RegisterHotKey with no-repeat, not a new keyboard logger. Upstream ScreenToGif's input hooks remain part of the inherited capture application. Diagnostic logs record configured shortcut labels, status and export paths, not arbitrary keystrokes.
- The explicit start-at-sign-in feature creates one HKCU Run entry named ScreenToGifQuickCapture, no elevated privileges, services, scheduled tasks or startup DLLs. Disable it from the settings or use Remove-Startup.cmd.
- Capture and added encoding are local. There are no added cloud calls. The patch disables upstream automatic update checking and queued automatic feedback sending; original manually invoked features and dependencies need separate assessment.
- Default recording is silent. Audio is explicitly armed via a capture shortcut or tray action, never retroactively enabled. An audio recording can contain other applications' sound or ambient conversations; verify consent and organizational restrictions before using it. Raw frames and WAVs may remain after crashes or failures.
- FFmpeg is resolved to a known local folder, executed without shell interpolation, and uses numbered local frame copies and safe concat mode. Preset values are validated and passed as separate process arguments. No arbitrary FFmpeg command or shell execution field is offered. Treat program directory as trusted: do not run from a location other users can write to.
- Temporary partial outputs are deleted after failed encoding and original frames remain for the editor. Successful export attempts to remove temporary project data; it does not securely erase storage. Do not rely on this for sensitive-data destruction. Output folder may be synced by other software.
- Build pins upstream tag/commit and NAudio 2.2.1; inspect all resolved dependencies, run current vulnerability checks and endpoint scanning, verify FFmpeg source/license and hash, and Authenticode-sign the release before managed deployment. .NET 9 support lifecycle and security updates should be reviewed before choosing the production baseline.
- Upstream ScreenToGif is MS-PL. NAudio is MIT; preserve notices and examine NuGet dependencies. FFmpeg build licensing varies, and libx264-enabled builds usually include GPL components. Verify applicable redistribution obligations, including corresponding source, before distributing any assembled binaries. The source preview does not bundle upstream or FFmpeg binaries. Original overlay code is provided for review and modification; preserve upstream license and notices in the fork.
